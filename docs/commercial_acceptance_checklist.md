# 小范围商用测试前验收清单

本文档供测试人员在交给业务同事小范围试用前逐项验收。当前版本状态统一为：商用测试版 / 内部试用版。当前测试版定位是本地记账、开奖记录、结算记录、操作日志、备份恢复和导出对账；第一阶段功能必须明确边界，不应被当成完整业务闭环。

测试前请准备：

- 独立测试数据库，不要使用生产 `data/fortune.db`。
- 可正常启动 Fortune 的 Python 环境。
- 至少一条可解析的正常录单文本、一条故意写错的异常录单文本。
- 至少一条可用于结算预览的开奖记录。
- 至少一个设置中心申报人和一个赔率/返水配置方案。

---

## 1. 录单窗口验收

**验收目标**
确认录单窗口可解析、预览、保存订单，并正确接入申报人配置和第一阶段高级选项。

**操作步骤**

1. 打开「我要录单」。
2. 确认申报人下拉框可读取设置中心配置；无配置时也能安全打开。
3. 选择一个申报人，确认旁边显示其绑定的配置方案或“未绑定配置方案”。
4. 输入正常订单，例如：`澳门 特码 01=10`。
5. 勾选「识别地区」和「智能纠错」，确认解析仍正常。
6. 保存订单并记录订单号。
7. 输入无效文本，确认保存被阻止。

**预期结果**

- 正常订单保存成功，订单详情中能看到真实申报人。
- 操作日志包含录单摘要、申报人和配置方案名称，但不记录导入/导出秘钥。
- 「识别地区」「智能纠错」「自动获取」可用。
- 录单高级选项特肖模式、岁写法、各->各肖已开放，只影响录单解析、预览和保存口径；不自动结算、不写余额、不涉及真实兑奖。
- 异常订单不会写入数据库。

---

## 2. 设置中心验收

**验收目标**
确认配置中心可保存本地配置，但不会自动参与赔付、返水或余额计算。

**操作步骤**

1. 打开主窗口右上角「设置」。
2. 在「赔率/返水」新增一个配置方案，新增一条投注类型、赔率、返水记录并保存。
3. 在「申报人」新增申报人，并绑定刚才的配置方案。
4. 在「导入/导出秘钥」保存导入秘钥和导出秘钥，测试显示/隐藏。
5. 关闭并重新打开设置中心，确认配置仍存在。

**预期结果**

- 三个标签页均可打开并持久化配置。
- 申报人配置能被录单窗口读取。
- 秘钥字段默认掩码显示，可切换显示/隐藏。
- 赔率配置可被结算只读读取用于基础中奖金额；返水、余额和客户账户仍不参与计算。

---

## 3. 订单详情验收

**验收目标**
确认订单详情页查询、筛选、导出、查看详情、作废、结算预览仍可用，并且新版筛选真实接入数据。

**操作步骤**

1. 进入「订单详情」。
2. 使用地区、状态、日期、关键词筛选刚保存的订单。
3. 使用「申报人」筛选。
4. 使用「投注类型」筛选。
5. 使用「中奖情况」筛选，至少验证「未结算」和已有结算记录状态。
6. 点击「过滤结算结果」和「综合结算摘要」。
7. 点击「扩大兑奖框」，再收起。
8. 选中订单后点击「查看订单详情」「结算预览」「作废订单」。
9. 导出订单 Excel，确认遵循当前筛选条件。

**预期结果**

- 申报人、投注类型、中奖情况筛选均使用真实数据。
- 「过滤结算结果」仅做只读统计，展示命中状态和快照中奖金额，不写余额。
- 「综合结算摘要」仅做只读汇总，不计算返水、佣金或余额。
- 「扩大兑奖框」只调整 UI。
- 「清空订单」「重置开奖」仍禁用并明确标注暂未开放；「导入订单」进入预览后只确认导入成功行。
- 作废订单需要原因，会写操作日志并触发自动刷新。

---

## 4. 开奖记录验收

**验收目标**
确认今日开奖和开奖历史读取真实数据，开奖同步、手工新增、修正选中开奖均可用。

**操作步骤**

1. 进入「今日开奖」，刷新澳门 / 香港开奖。
2. 进入「开奖历史」，测试查询、重置、分页。
3. 点击「获取最新数据」。
4. 点击「同步历史数据」并按界面提示操作。
5. 点击「手工新增开奖」，新增一条测试开奖记录。
6. 选中开奖记录后确认「修正选中开奖」可用，并完成一次修正。

**预期结果**

- 页面不显示假开奖数据。
- 手工新增和修正会写操作日志。
- 开奖变化后今日开奖、开奖历史、订单详情下方开奖展示等自动刷新。
- 修正操作有确认提示，不能静默改数据。

---

## 5. 结算验收

**验收目标**
确认结算预览、正式结算、结算记录持久化和快照详情可用，同时明确当前只计算基础中奖金额，不写余额。

**操作步骤**

1. 在订单详情中选中待处理订单。
2. 点击「结算预览」，选择匹配地区和期号的开奖记录。
3. 查看命中、未中、不支持明细。
4. 对支持玩法点击「正式确认结算」，完成二次确认。
5. 返回订单详情，查看中奖情况和底部结算摘要。
6. 进入「结算历史」，查看结算流水和快照详情。
7. 尝试对已结算订单再次结算。

**预期结果**

- 结算预览关闭后不修改订单状态。
- 正式结算成功后生成 SettlementRecord 和 result_snapshot。
- 已结算订单防重复结算。
- 存在不支持玩法时阻断正式结算并说明原因。
- 复杂玩法结算未完全开放。
- 命中项显示基础中奖金额；不处理余额、返水、佣金或完整账务盈亏。

---

## 6. 特码调单验收

**验收目标**
确认特码调单第一阶段页面可用，保存的只是调单快照记录，不会修改原订单或自动兑奖。

**操作步骤**

1. 点击「特码调单」主导航。
2. 查看左侧号码汇总表和右侧 01-49 调整区。
3. 切换「全部 / 只看澳门 / 只看香港」。
4. 输入临时调整值，确认总计仅在页面内变化。
5. 点击「调整成为 10 的倍数」「清空当前调整」「清空输出框」。
6. 点击「保存本次调整」「重置所有数据」「特码兑奖」「打开拓展」「调整记录」。

**预期结果**

- 页面可打开并显示真实订单汇总或空状态。
- 临时调整只影响页面；保存本次调整只写调单快照记录和操作日志，不修改订单。
- 「重置所有数据」「特码兑奖」「打开拓展」仍只提示，不执行真实兑奖、重置或余额业务。
- 不自动兑奖，不写余额。

---

## 7. 连肖调单验收

**验收目标**
确认连肖调单第一阶段只读汇总可用，布局为左侧总表 + 右侧四个连肖列表。

**操作步骤**

1. 鼠标悬停或使用「特码调单」旁下拉入口，进入「连肖调单」。
2. 查看左侧总表和右侧四个并排连肖列表。
3. 切换「全部 / 只看澳门 / 只看香港」。
4. 点击「打印连肖调整」「清空输出框」「重置调整」。

**预期结果**

- 页面不出现「原金额 / 调整 / 总计」调整网格。
- 页面不出现调整输入框。
- 页面保留「保存本次调整」用于保存调单快照记录，不修改原订单、不自动兑奖。
- 「打印连肖调整」当前只提示请复制或导出后打印。
- 「重置调整」只重置页面临时状态。
- 不修改订单、不自动兑奖、不写余额、不计算完整账务盈亏。

---

## 8. 拆单助手验收

**验收目标**
确认拆单助手第一阶段文本整理、订单预览和勾选保存成功行可用。

**操作步骤**

1. 进入「辅助工具」，打开拆单助手。
2. 输入包含空行、连续空格、中文逗号、顿号、分号、英文逗号/分号的文本。
3. 点击「开始拆分」。
4. 点击「调整拆分结果样式」，再次点击取消序号。
5. 点击「复制结果」。
6. 点击「保存拆分结果到文件」，保存为 txt。
7. 点击「预览订单」，查看成功 / 失败行。
8. 勾选解析成功行并点击「确认保存成功行」。
9. 点击「清空输入」。

**预期结果**

- 能去空行、压缩空格并按分隔符拆成多行。
- 复制结果写入剪贴板。
- 保存结果为 UTF-8 txt。
- 能预览订单并保存勾选的解析成功行。
- 解析失败行、未勾选行和已保存行不会重复保存；不自动结算、不计算赔付或余额。

---

## 9. 操作日志验收

**验收目标**
确认关键业务操作均写日志，日志查询可用，清空日志仍未开放。

**操作步骤**

1. 进入「操作日志」。
2. 查询今日日志，定位录单、作废、结算、开奖维护、备份、恢复、导出等操作。
3. 导出操作日志 Excel。
4. 查找是否存在「清空日志」按钮。

**预期结果**

- 关键操作均有日志。
- 日志内容为真实操作摘要。
- 可导出 Excel。
- 不提供清空日志入口；页面说明清空日志为高风险功能暂未开放。

---

## 10. 自动刷新验收

**验收目标**
确认数据变更后相关页面自动刷新，不依赖定时轮询。

**操作步骤**

1. 保存新订单，观察数据总览、订单分析、订单详情、操作日志。
2. 作废订单，观察订单详情、数据总览、订单分析、操作日志。
3. 正式结算，观察订单详情、结算历史、操作日志、数据总览、订单分析。
4. 手工新增或修正开奖，观察今日开奖、开奖历史、订单详情开奖展示。
5. 修改设置中心申报人，观察录单窗口申报人下拉和订单详情申报人筛选。
6. 从备份恢复数据库，重启或按提示检查页面数据。

**预期结果**

- 相关页面自动刷新。
- 手动刷新按钮仍保留。
- 当前筛选、搜索、分页状态不应被无故清空。
- 刷新失败时有安全提示或日志，不导致主程序崩溃。

---

## 11. 数据库备份 / 恢复验收

**验收目标**
确认数据库备份、恢复可用，恢复前自动备份当前库。

**操作步骤**

1. 进入「辅助工具」。
2. 点击「立即备份」。
3. 刷新备份列表，确认新备份出现。
4. 选择测试备份，点击「从备份恢复」。
5. 阅读确认对话框并执行恢复。

**预期结果**

- 备份成功，文件位于 `data/backups/`。
- 恢复前有风险确认。
- 恢复前自动备份当前库。
- 恢复成功后触发全局刷新或提示重启。

---

## 12. Excel 导出验收

**验收目标**
确认订单、结算流水、操作日志均可导出，且导出不修改业务数据。

**操作步骤**

1. 在订单详情按筛选条件导出 Excel。
2. 在结算历史导出 Excel。
3. 在操作日志导出 Excel。
4. 打开文件核对列名、中文、数据条数。

**预期结果**

- Excel 可打开，中文无乱码。
- 订单导出遵循当前筛选条件。
- 导出不修改订单、结算或日志状态。

---

## 13. 防误操作验收

**验收目标**
确认高风险入口禁用或明确提示，第一阶段功能不会误写业务库。

**操作步骤**

1. 检查订单详情中的「清空订单」「重置开奖」。
2. 检查「导入订单」可进入预览，并且只确认导入成功行。
3. 检查操作日志是否没有「清空日志」入口。
4. 检查特码调单、连肖调单、拆单助手边界提示。
5. 尝试重复结算已结算订单。

**预期结果**

- 清空订单、重置开奖禁用。
- 导入订单为第一阶段可用，只保存确认导入的成功行。
- 清空日志不开放。
- 调单只写调单快照记录；拆单助手只保存勾选的解析成功订单行。
- 已结算订单不能重复正式结算。

---

## 14. 数据库文件安全验收

**验收目标**
确认测试与交付流程不会误提交、误打包真实业务数据库。

**操作步骤**

1. 确认试用环境使用独立测试库。
2. 运行只读自检：

```bash
python scripts/pre_release_check.py --project-root .
```

3. 确认 Git 未跟踪 `data/fortune.db`、`data/backups/`、`exports/` 下业务文件。

**预期结果**

- 生产/试用真实数据与源码仓库隔离。
- 自检脚本仅报告，不删除文件。
- 备份和恢复记录可追溯。

---

## 15. 小范围试用前注意事项

**验收目标**
测试负责人确认团队已理解当前功能边界。

**操作步骤**

1. 向试用人员说明当前可稳定验证录单、开奖、订单详情、结算记录、日志、备份恢复和导出。
2. 说明未确认复杂玩法、余额、返水/佣金、权限仍未开放；订单导入和基础中奖金额已进入第一阶段。
3. 说明调单页面和拆单助手均为第一阶段功能。
4. 说明每日或每批次操作后应执行备份。
5. 出现问题时保留订单号、期号、截图、操作日志导出文件。

**预期结果**

- 试用人员知晓功能边界、备份要求、问题上报方式。
- 试用数据与生产数据物理隔离。
- 所有核心验收项通过后才进入小范围商用。
