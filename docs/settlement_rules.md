# 中奖判定规则说明

本阶段只实现“是否中奖”的只读预览，不计算赔付金额、返水、佣金、盈亏，不修改订单状态，也不写兑奖记录。

调用方必须显式传入一张订单和指定的一期开奖结果。结算服务不会自动选择最新开奖，避免把订单匹配到不确定期号。

## 需要确认的业务口径

1. 解析器展开后的“纯数字”是否永远表示特码号码投注，还是有时表示平码或全号命中。
2. 连肖、连尾、多生肖、全包等组合玩法到底按特码、全部 7 个号码，还是组合计奖规则判定。
3. 头数是否需要开放 `0头`，本阶段为兼容 `01-09` 的头数规则已支持。
4. 后续计算赔付金额时，赔率字段的业务来源和多号码拆单规则需要再确认。
