# 结算验收样例

说明：

- 中奖金额 = 命中项投注金额 x 赔率；未配置赔率时中奖金额为 0.00 并显示未配置提示。
- 返水金额 = 有效投注额 x 返水比例；无返水配置时为 0.00。
- 统计结算金额 = 中奖金额 + 返水金额 - 投注本金。
- 所有金额都是结算快照 / 统计参考，不代表真实付款、收款或入账。
