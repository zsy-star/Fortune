# 高风险维护与产品范围外检查清单

本清单用于发布前确认：已开放高风险维护入口都受保护，仍未开放入口没有误开放，产品范围外能力没有误出现。

## 高风险维护入口第一阶段

这些能力已开放，但必须经过自动备份、二次确认、原因必填、确认短语和操作日志，不得静默执行：

| 检查项 | 期望状态 | 验收结果 | 备注 |
| --- | --- | --- | --- |
| 清空订单 | 受保护开放 |  | 删除 orders、order_items、settlement_records；不删除开奖、日志、设置 |
| 清空日志 | 受保护开放 |  | 先备份数据库并归档日志，清空后保留一条新维护日志 |
| 批量删除订单 | 受保护开放 |  | 只删除选中订单及对应明细、结算快照 |
| 重置开奖记录 | 条件开放 |  | 无结算记录时可执行；存在结算记录时阻断 |

## 高风险未开放

这些能力后续可以评估，但当前发布前必须保持未开放，或仅显示明确提示：

| 检查项 | 期望状态 | 验收结果 | 备注 |
| --- | --- | --- | --- |
| 权限 / 登录 / 角色 / 审批 | 暂未开放 |  | 留到最后统一设计 |
| 真正修改原订单式调单 | 暂未开放 |  | 当前只保存调单快照 |
| 连肖复选正式结算 | 不支持 |  | 需要参考软件中奖样例 |
| 正码特 | 不支持或无正式规则 |  | 需要参考软件样例 |
| 特串 | 不支持或无正式规则 |  | 需要参考软件样例 |
| 正式安装包和升级流程 | 暂未冻结 |  | 需要发布、备份、回滚策略 |
