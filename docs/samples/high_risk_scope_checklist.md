# 高风险未开放与产品范围外检查清单

本清单用于发布前确认：高风险入口没有误开放，产品范围外能力没有误出现。

## 高风险未开放

这些能力后续可以评估，但当前发布前必须保持未开放，或仅显示明确提示：

| 检查项 | 期望状态 | 验收结果 | 备注 |
| --- | --- | --- | --- |
| 权限 / 登录 / 角色 / 审批 | 暂未开放 |  | 留到最后统一设计 |
| 清空订单 | 禁用或无入口 |  | 需要权限、备份、审计 |
| 清空日志 | 禁用或无入口 |  | 日志用于追溯 |
| 批量删除 | 禁用或无入口 |  | 需要恢复策略 |
| 重置开奖 | 禁用或无入口 |  | 会影响结算依据 |
| 真正修改原订单式调单 | 暂未开放 |  | 当前只保存调单快照 |
| 连肖复选正式结算 | unsupported |  | 需要参考软件中奖样例 |
| 正码特 | unsupported 或无正式规则 |  | 需要参考软件样例 |
| 特串 | unsupported 或无正式规则 |  | 需要参考软件样例 |
| 正式安装包和升级流程 | 暂未冻结 |  | 需要发布、备份、回滚策略 |
