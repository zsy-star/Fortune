## 验收失败如何记录

1. **步骤编号**：例如「步骤 9 正式确认结算」
2. **复现步骤**：按顺序写清点击与输入
3. **预期 vs 实际**：各一行
4. **证据**：截图、订单号、期号、弹窗全文、操作日志导出
5. **严重程度**：阻塞 / 严重 / 一般 / 建议
6. **环境**：Python 版本、提交哈希、数据库是否测试库
7. **上报**：交给开发时附 `docs/commercial_acceptance_checklist.md` 对应章节
