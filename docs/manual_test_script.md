# 小范围单机试用版人工验收脚本

本脚本用于 V1.0 小范围单机试用版封版验收。验收时不要使用真实 `data/fortune.db`，应使用独立测试库、临时测试环境或可丢弃的测试数据目录；如必须接触真实库，只能先备份并执行只读检查。

Fortune 是本地单机记账和统计工具，不做客户余额、不做真实付款、不做真实兑奖入账、不做云同步。中奖金额、返水金额和统计结算金额只作为结算快照 / 对账参考。

## 验收准备

1. 准备独立测试库或临时测试环境。
2. 准备一个申报人和一个赔率 / 返水配置方案。
3. 准备特码订单、连肖订单、暂不支持正式结算玩法订单各一组。
4. 准备一期开奖结果，确保可用于结算预览。
5. 验收前执行一次数据库备份。

## 1. 首次启动 / 设置中心

1. 启动程序，确认主窗口可打开。
2. 打开设置中心。
3. 新增或编辑赔率 / 返水方案。
4. 保存导入 / 导出秘钥，确认默认掩码显示，可切换显示。
5. 关闭并重新打开设置中心，确认配置仍在。

预期：设置只保存在本机，不涉及云同步；赔率用于中奖金额快照，返水只作为统计项。

## 2. 申报人配置

1. 在设置中心新增申报人。
2. 将申报人绑定到一个赔率 / 返水方案。
3. 打开录单窗口，确认申报人下拉框能读取配置。
4. 选择申报人，确认界面显示绑定方案。

预期：录单保存时能记录申报人；不生成客户账户或余额。

## 3. 录入特码订单

1. 打开录单窗口。
2. 输入特码订单，例如 `澳门 特码 01=10`。
3. 点击预览，核对地区、玩法、号码、金额和总额。
4. 保存订单，记录订单号。
5. 到订单详情中查询该订单。

预期：订单保存成功，写操作日志；不自动结算、不写余额。

## 4. 录入连肖订单

1. 输入连肖订单，例如 `澳门 连肖 马蛇 各10`。
2. 预览并核对金额口径。
3. 保存订单，记录订单号。
4. 在订单详情中查询。

预期：连肖订单可作为记账订单保存；正式结算以当前结算支持范围为准。

## 5. 录入暂不支持正式结算的玩法

1. 输入暂不支持正式结算的玩法，例如连肖复选、二中特或特串。
2. 预览并保存为记账订单。
3. 在订单详情中点击结算预览或正式结算入口。

预期：界面必须强提示暂不支持正式结算；正式结算应阻断，不写 SettlementRecord，不改变订单状态。

## 6. 今日开奖 / 开奖历史

1. 进入今日开奖，刷新澳门 / 香港开奖。
2. 进入开奖历史，使用地区、期号或日期查询。
3. 翻页、重置查询条件。

预期：显示真实库中的开奖记录或空状态，不显示假数据。

## 7. 手工新增开奖

1. 在开奖历史点击手工新增开奖。
2. 输入地区、期号、开奖日期、6 个正码和 1 个特码。
3. 保存后回到列表查询。

预期：新开奖保存成功，写操作日志；号码校验生效。

## 8. 修正开奖

1. 选中一条测试开奖记录。
2. 点击修正开奖。
3. 修改号码或日期。
4. 留空原因尝试保存，再填写原因保存。

预期：修正开奖必须填写原因，保存后写操作日志；不得静默修改。

## 9. 订单详情查询

1. 使用订单号、地区、状态、申报人、投注类型查询订单。
2. 打开订单详情。
3. 查看订单明细、原始文本、操作日志摘要和结算摘要。
4. 导出订单表格，确认遵循筛选条件。

预期：查询结果正确，导出不修改业务数据。

## 10. 结算预览

1. 选中待结算订单。
2. 点击结算预览。
3. 选择匹配地区和期号的开奖。
4. 核对命中 / 未中 / 不支持、中奖金额、返水金额、统计结算金额。

预期：预览只读，不改变订单状态；统计结算金额 = 中奖金额 + 返水金额 - 投注本金。

## 11. 正式结算

1. 在结算预览确认支持玩法无阻断。
2. 点击正式结算。
3. 阅读二次确认内容后确认。
4. 返回订单详情查看状态。

预期：生成结算记录和快照，订单状态变为已结算，写操作日志；重复正式结算必须阻断。

## 12. 结算历史查看快照

1. 进入结算历史。
2. 查询刚完成的结算记录。
3. 打开结算快照详情。
4. 核对订单、开奖、明细、中奖金额、返水金额、统计结算金额。

预期：快照只读展示，不提供重新结算或修改状态入口。

## 13. 结算流水 Excel 导出

1. 在结算历史设置筛选条件。
2. 点击导出表格。
3. 打开导出的 Excel。
4. 确认表头包含：中奖金额、返水金额、统计结算金额。
5. 对照界面快照核对金额。

预期：导出字段适合对账；旧结算记录缺少对应快照字段时导出为 0 或空值，不重新计算结算算法。

## 14. 特码调单保存抛出记录

1. 进入特码调单。
2. 查看 01-49 风险表。
3. 输入抛出内容，例如 `25=100`。
4. 不填原因尝试保存，再填写原因保存。
5. 查看调整记录。

预期：保存抛出记录和操作日志；不修改原订单，不重新结算，不写余额。

## 15. 连肖调单保存抛出记录

1. 进入连肖调单。
2. 查看连肖组合风险表。
3. 输入抛出内容，例如 `龙羊猴=100`。
4. 不填原因尝试保存，再填写原因保存。
5. 查看调整记录。

预期：同一组合不同顺序可归一；保存调单记录和操作日志，不修改订单。

## 16. 调整记录撤销

1. 打开调整记录。
2. 选择 active 状态的特码或连肖抛出记录。
3. 执行撤销。
4. 尝试撤销 legacy / reversal 记录。

预期：active 可撤销并新增 reversal 记录；legacy / reversal 不可撤销；不删除原记录。

## 17. 数据库备份

1. 进入辅助工具或备份恢复入口。
2. 点击立即备份。
3. 刷新备份列表。
4. 记录备份文件名。

预期：备份文件写入 `data/backups/`，操作日志可追溯。

## 18. 数据库恢复前自动备份

1. 选择一个测试备份。
2. 点击从备份恢复。
3. 阅读风险提示和确认内容。
4. 执行恢复。

预期：恢复前自动备份当前库；恢复成功后提示刷新或重启；不要在真实 `data/fortune.db` 上做封版验收。

## 19. 操作日志查询和导出

1. 进入操作日志。
2. 查询录单、开奖、结算、调单、备份、恢复、导出等操作。
3. 导出操作日志 Excel。
4. 打开文件核对时间、模块、动作、摘要。

预期：关键操作均有日志；导出不修改日志。

## 20. 高风险入口受保护确认

1. 检查清空订单入口。
2. 检查批量删除订单入口。
3. 检查清空日志入口。
4. 检查重置开奖记录入口。
5. 逐项确认是否进入统一保护流程。

预期：这些入口不是完全禁用，但必须受保护执行：自动备份、二次确认、原因填写、确认短语、操作日志。清空日志需先归档日志；重置开奖记录在存在结算记录时阻断。不建议日常频繁使用，小范围试用时应先备份再操作。当前不是完整权限系统，仍依赖本机管理和操作规范。

## 验收收尾

1. 导出订单、结算流水和操作日志。
2. 再执行一次数据库备份。
3. 保存问题信息：订单号、期号、地区、截图、操作日志导出、备份文件名。
4. 确认没有把测试库、备份库、测试 xlsx、dist 或 build 产物纳入提交。
