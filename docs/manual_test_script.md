## 步骤 4A：录单高级选项验收样例

| 模式 | 输入样例 | 预期 |
|------|----------|------|
| 普通模式 | `01各10` | 号码投注，总额 10 |
| 普通模式 | `01,02,03各10` | 多号码投注，总额 30 |
| 普通模式 | `马各10` | 普通特码生肖，2026 马肖 5 个号码，总额 50 |
| 普通模式 | `羊马各10` | 普通特码生肖，羊 4 个号 + 马 5 个号，总额 90 |
| 普通模式 | `红波各10` / `红单各10` / `大各10` / `单各10` | 波色、半波、大小、单双原解析不变 |
| 勾选各->各肖 | `羊马各10` | 按生肖个数计算，总额 20 |
| 勾选各->各肖 | `鼠牛虎各5` / `鼠、牛、虎各5` | 3 个生肖，总额 15 |
| 勾选各->各肖 | `01,02各10` / `红波各10` | 不受各->各肖影响，原解析不变 |
| 勾选特肖模式 | `马10` | 按平特一肖 / 特肖解析，总额 10 |
| 勾选特肖模式 | `马蛇10` | 2 个生肖，总额 20 |
| 勾选特肖模式 | `龙-羊-猴各80` | 3 个生肖，总额 240 |
| 勾选特肖模式 | `01各10` / `红波各10` | 不受特肖模式影响，原解析不变 |
| 勾选岁写法 | `25岁各10` / `08岁各10` / `1岁各10` | 分别识别为 25、08、01，单号总额 10 |
| 勾选岁写法 | `25岁、08岁各10` | 识别为 25、08，总额 20 |
| 勾选岁写法 | `50岁各10` / `00岁各10` | 解析失败，不能保存 |
| 三项同时勾选 | `25岁、08岁各10` | 优先按岁写法识别号码，总额 20 |
| 三项同时勾选 | `羊马各10` | 各->各肖生效，总额 20 |
| 三项同时勾选 | `马蛇10` | 特肖模式生效，总额 20 |
| 三项同时勾选 | `01各10` | 仍为号码投注，总额 10 |

**预期**：高级选项只改变上述对应样例的解析和金额口径；添加到表格后如手动调整金额，保存以表格当前金额为准；申报人、地区、渠道仍进入订单保存链路。

## 验收失败如何记录

1. **步骤编号**：例如「步骤 9 正式确认结算」
2. **复现步骤**：按顺序写清点击与输入
3. **预期 vs 实际**：各一行
4. **证据**：截图、订单号、期号、弹窗全文、操作日志导出
5. **严重程度**：阻塞 / 严重 / 一般 / 建议
6. **环境**：Python 版本、提交哈希、数据库是否测试库
7. **上报**：交给开发时附 `docs/commercial_acceptance_checklist.md` 对应章节
