# 人工验收脚本

当前版本状态统一为：商用测试版 / 内部试用版。

本脚本用于发布前人工验收。Fortune 是本地记账、号码录入、订单统计、开奖核对、中奖金额快照和返水金额统计工具；不做客户账户、不做客户余额、不做余额流水、不做真实兑奖入账，不涉及真实资金支付。

## 1. 设置中心

| 操作 | 验收点 |
| --- | --- |
| 打开设置中心 | 能看到赔率/返水、申报人、导入/导出秘钥页签 |
| 新增赔率/返水方案 | 可新增、编辑、保存赔率和返水记录 |
| 绑定申报人 | 申报人可绑定方案并保存 |

预期：赔率用于中奖金额快照；返水作为统计项保留，不入账、不付款、不形成客户余额。

## 2. 录单

| 操作 | 验收点 |
| --- | --- |
| 打开录单窗口 | 高级选项可用：识别地区、智能纠错、特肖模式、岁写法、各->各肖 |
| 录单工具栏安全项 | 去除空行、去分隔符 / 统一分隔符、去空格、号码补零、重复号码提示、快速预览、复制预览、清空当前输入等工具只作用于当前输入框或当前预览 |
| 号码补零 | `平码 1,2,9各10` 可整理为两位号码；不误伤金额、`复2`、`三中二`、`二中二`、`1头`、`尾1`、`1岁`、括号组合和拖式 `/` 写法 |
| 清空当前输入 | 点击清空结果时必须二次确认；确认后只清空当前输入、输出和预览表，不清空数据库订单 |
| 输入订单并预览 | 金额、总额、玩法、selection 正常 |
| 输入复杂玩法 | `复3 01,02,03,04 各10` 总额 40；`二中二 01,02,03,04,05 拖 06,07,08,09,10 各5` 总额 125；`平尾 1,3,4,6 各1000` 总额 4000 |
| 保存订单 | 成功订单进入订单详情，写操作日志 |

预期：高级选项只影响录单解析、预览和保存口径；工具栏只整理当前输入或复制当前预览，不修改历史订单、不自动结算、不写余额、不做真实兑奖。

## 3. 订单导入 / 拆单助手

| 操作 | 验收点 |
| --- | --- |
| 导入 txt/csv/xlsx | 可预览、检测历史重复、确认导入成功行 |
| 使用拆单助手 | 可整理文本、预览订单、勾选保存成功行 |

预期：导入和拆单可保存确认的成功订单，不自动结算，不产生资金流水。

## 4. 开奖

| 操作 | 验收点 |
| --- | --- |
| 同步开奖 | 新开奖进入开奖记录 |
| 手动新增开奖 | 合法号码可保存，写操作日志 |
| 修正开奖 | 选中记录后可修正，写操作日志 |

预期：开奖数据用于核对与结算，不提供重置开奖入口。

## 5. 结算

| 操作 | 验收点 |
| --- | --- |
| 订单详情点击结算预览 | 显示命中 / 未中 / unsupported、赔率、中奖金额、返水金额、统计结算金额 |
| 复杂玩法结算预览 | 平尾只看 6 个正码尾数；二中二 / 三中三 / 三中二只看 6 个正码；几中几复选 `复2/复3` 按展开组合判断；连肖复选仍显示 unsupported |
| 正式结算 | 生成 SettlementRecord 和 result_snapshot |
| 查看结算历史 | 可查看结算快照详情 |

预期：中奖金额、返水金额和统计结算金额来自结算快照；统计结算金额 = 中奖金额 + 返水金额 - 投注本金。当前不做真实兑奖入账，不写客户余额，不付款；返水只作为统计项 / 快照字段展示。

## 6. 调单与打印文本

| 操作 | 验收点 |
| --- | --- |
| 特码调单 / 连肖调单 | 可保存调单快照 |
| 查看调整记录 | 可查看、复制、导出 |
| 打印文本 | 只生成可复制 / 可导出的打印文本，不接入真实打印机、打印机驱动、静默打印或打印模板编辑器 |

预期：调单不修改原订单、不自动兑奖、不写余额；打印能力以文本生成、复制、导出为准。

## 7. 高风险未开放与产品范围外

| 检查项 | 验收点 |
| --- | --- |
| 主导航 | 不显示“客户账户”页面入口 |
| 订单详情 | 不显示“兑奖入账 / 已入账 / 入账流水 / 客户余额”入口或状态 |
| 结算历史 | 不显示“兑奖入账 / 已入账 / 入账流水 / 客户余额”入口或状态 |
| 高风险未开放 | 权限系统 / 登录 / 角色 / 审批、清空订单、清空日志、批量删除、重置开奖、真正修改原订单式调单、正式安装包和升级流程暂未开放；这些能力需要权限、二次确认、操作日志、备份或管理员确认 |
| 规则待确认 | 连肖复选、正码特、特串等规则未确认玩法需要参考软件样例，未确认前不开放正式结算 |
| 明确不纳入当前产品范围 | 客户账户、客户余额、余额流水、钱包系统、支付系统、真实付款、真实收款、真实兑奖入账、真实打印机调用、打印机驱动适配、静默打印、打印模板编辑器、云同步 / 在线账号不作为正式商用必做缺口 |

预期：系统没有客户账户、余额流水、真实支付、真实兑奖入账链路；打印能力以文本生成、复制、导出为准；返水和中奖金额只作为结算快照 / 统计参考。
