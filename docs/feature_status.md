# 功能状态总览

本文记录 Fortune 当前商用测试版 / 内部试用版的功能状态。Fortune 定位为单机记账本、号码录入工具、订单统计工具、开奖核对工具、中奖金额快照工具、返水金额计算工具和结算统计工具。

Fortune 不做客户账户、不做客户余额、不做余额流水、不做真实兑奖入账，不涉及真实资金支付。中奖金额和返水金额都是结算快照 / 统计参考，不代表已经收款、付款或入账。

| 功能 | 状态 | 说明 |

## 复杂玩法边界

| 玩法 | 状态 | 说明 |
| --- | --- | --- |
| N不中 / 不中 | 已对齐 | 保存为一条整组订单，金额按整组金额；结算口径为全部开奖号码均未出现才命中。 |
| 连肖 | 已对齐 | 保存为一条整组订单，金额不按生肖个数或生肖下号码数相乘；结算沿用当前支持范围。 |
| 几中几复选 | 已支持第一阶段 | 按组合数 `C(n,k)` 计算总额；`复2` 按二中二组合结算，`复3` 按三中三组合结算。 |
| 连肖复选 | 录单金额预览已支持 | 按组合数 `C(n,k)` 计算总额；正式结算仍 unsupported，等待参考软件中奖样例。 |
| 二中二 / 三中三 / 三中二 | 已支持第一阶段 | 单组总额 = 金额，多组或拖式总额 = 金额 x 组合组数；正式结算只看 6 个正码，不看特码。 |
| 平尾 | 已支持第一阶段 | 金额按尾数个数计算；正式结算只看 6 个正码尾数，特码不参与。 |
| 正码特 / 特串 | 待补样例 | 更新日志明确存在但缓存无样本，本阶段不猜规则。 |
| 独立名义的胆拖、组选、全包 | 正式结算未开放 | 底层能力已按复选、连码组合和二中二拖式 / 分组组合覆盖；不新增独立资金玩法名。 |

## 明确不纳入当前产品范围

以下能力不属于当前产品定位，不作为正式商用必做缺口；当前版本不计划实现，产品以本地记账、统计、开奖核对、中奖查看、返水统计和打印文本为准。

- 客户账户。
- 客户余额。
- 余额流水。
- 手工加款 / 手工扣款。
- 钱包系统。
- 支付系统。
- 真实兑奖入账。
- settlement_payout 账户流水。
- 真实支付 / 收款 / 付款。
- 真实打印机调用。
- 打印机驱动适配。
- 静默打印。
- 打印模板编辑器。
- 冲正 / 回滚 UI。
- 云同步 / 在线账号。
