# 功能状态总览

本文记录 Fortune 当前测试版的功能状态。状态含义：

- 已完成：当前可按测试版目标正常使用。
- 第一阶段可用：功能有明确边界，可用但不覆盖完整业务链路。
- 只读展示：只读取和展示数据，不写数据库。
- 安全占位：保留入口，但只提示或只做页面临时操作。
- 暂未开放：当前不提供入口或入口禁用。
- 高风险暂不开放：涉及删除、权限、账务、真实赔付等，未完成审计和规则设计前不开放。
