# 功能状态总览

本文记录 Fortune 当前商用测试版 / 内部试用版的功能状态。Fortune 定位为单机记账本、号码录入工具、订单统计工具、开奖核对工具、中奖金额快照工具、返水金额计算工具和结算统计工具。

Fortune 不做客户账户、不做客户余额、不做余额流水、不做真实兑奖入账，不涉及真实资金支付。中奖金额和返水金额都是结算快照 / 统计参考，不代表已经收款、付款或入账。

## 已开放

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 录单、预览、保存订单 | 已开放 | 通过服务层保存，不由 UI 直接写 ORM。 |
| 录单高级选项 | 已开放 | 识别地区、智能纠错、特肖模式、岁写法、各->各肖已开放；只影响录单解析、预览和保存口径。 |
| 订单查询、详情、导出、作废 | 已开放 | 支持申报人、投注类型、中奖情况等筛选。 |
| 订单导入 | 已开放 | 支持 txt/csv/xlsx、模板、申报人、渠道、历史重复检测、确认导入成功行。 |
| 拆单助手保存订单 | 第一阶段可用 | 支持文本整理、订单预览、勾选保存成功行。 |
| 开奖同步、手动新增、修正 | 已开放 | 保留操作日志。 |
| 结算预览、正式结算、结算历史 | 已开放 | 保留命中 / 未中 / unsupported、赔率、中奖金额快照、返水金额快照和统计结算金额。 |
| 赔率/返水配置方案 | 已开放 | 保留 `odds_rebate_plans` 和 `odds_rebate_items`；申报人可绑定配置方案。 |
| 返水金额 | 统计项 | 返水按订单明细投注额和赔率 / 返水配置中的返水比例计算，并保存到结算快照；统计结算金额 = 中奖金额 + 返水金额 - 投注本金；不入账、不付款、不形成客户余额。 |
| 订单分析 | 已开放 | 用于订单统计和结算统计，不等于完整真实盈亏。 |
| 操作日志 | 已开放 | 记录关键操作，不提供清空入口。 |
| 特码调单 / 连肖调单 | 第一阶段可用 | 保存调单快照，不修改原订单、不自动兑奖、不写余额。 |
| 设置中心、备份恢复、号码大全、计算器 | 已开放 | 本地辅助功能。 |

## 复杂玩法边界

| 玩法 | 状态 | 说明 |
| --- | --- | --- |
| N不中 / 不中 | 已对齐 | 保存为一条整组订单，金额按整组金额；结算口径为全部开奖号码均未出现才命中。 |
| 连肖 | 已对齐 | 保存为一条整组订单，金额不按生肖个数或生肖下号码数相乘；结算沿用当前支持范围。 |
| 几中几复选 / 连肖复选 | 录单金额预览已支持 | 按组合数 `C(n,k)` 计算总额；正式结算仍 unsupported。 |
| 二中二 / 三中三 / 三中二 | 录单金额预览已支持 | 单组总额 = 金额，多组总额 = 金额 x 组合组数；正式结算仍 unsupported。 |
| 平尾 | 录单金额预览已支持 | 金额按尾数个数计算；正式结算仍 unsupported。 |
| 胆拖、组选、全包等规则未确认玩法 | 正式结算未开放 | 需要更多样例确认规则后再实现。 |

## 不纳入当前产品范围

- 客户账户。
- 客户余额。
- 余额流水。
- 手工加款 / 手工扣款。
- 真实兑奖入账。
- settlement_payout 账户流水。
- 真实支付 / 收款 / 付款。
- 冲正 / 回滚 UI。

## 仍未开放

- 权限系统 / 登录 / 角色 / 审批。
- 清空订单。
- 清空日志。
- 批量删除。
- 重置开奖。
- 真实修改原订单式调单。
- 真实打印机调用。
- 云同步 / 在线账号。
- 正式安装包。
- 规则未确认的胆拖、组选、全包等复杂玩法正式结算。
