# 功能状态总览

本文记录 Fortune 当前商用测试版 / 内部试用版的功能状态。当前版本用于小范围商用记账验证，功能边界以本文档为准。状态含义：

- 已完成：当前可按测试版目标正常使用。
- 第一阶段可用：功能有明确边界，可用但不覆盖完整业务链路。
- 只读展示：只读取和展示数据，不写数据库。
- 安全占位：保留入口，但只提示或只做页面临时操作。
- 暂未开放：当前不提供入口或入口禁用。
- 高风险暂不开放：涉及删除、权限、账务、真实赔付等，未完成审计和规则设计前不开放。

## 未开放功能冻结清单

- 余额流水 / 客户账户：账务模型、审计口径和回滚策略尚未设计，不写客户余额。
- 返水 / 佣金：当前只计算基础中奖金额，返水和佣金不参与结算。
- 权限系统：角色、授权范围和管理员审计尚未设计，不开放高风险维护权限。
- 清空订单：破坏性操作，需要权限、审计和恢复策略支持。
- 清空日志：操作日志用于追溯订单、结算、备份恢复等关键行为，不提供清空入口。
- 批量删除：需要权限、审计和恢复策略支持，当前不开放。
- 重置开奖：会影响结算依据，需要权限、审计和恢复策略支持。
- 真实兑奖：涉及结算、赔付、余额流水和审计，当前不执行真实兑奖。
- N不中：已对齐为一条整组订单，结算只判断全部开奖号码均未出现才命中；中奖金额仍只走基础赔率公式，不写余额、不计算返水或佣金。
- 连肖：已对齐为一条整组订单，录单金额不按生肖个数或生肖下号码数相乘；完整连肖中奖规则仍以当前 Fortune 简化支持范围为准，不写余额、不计算返水或佣金。
- 几中几复选 / 连肖复选：录单金额预览已支持，按 `C(n,k)` 计算总额并保存一条汇总明细；正式结算统一返回“复选类玩法结算规则待确认”，不计算赔付、不写余额、不处理返水或佣金。
- 二中二 / 三中三 / 三中二：录单金额预览已支持，按组合组数计算总额并保存一条汇总明细；正式结算统一返回“连码类玩法结算规则待确认”，不计算赔付、不写余额、不处理返水或佣金。
- 平尾：录单金额预览已支持，按尾数个数计算总额并保存一条汇总明细；正式结算统一返回“平尾结算规则待确认”，不计算赔付、不写余额、不处理返水或佣金。
- 真实修改原订单式调单：需要审计、权限和回滚策略，当前调单只保存快照。
- 真实打印机调用：需要打印模板和设备适配，当前只生成可复制/导出的打印文本。
- 录单窗口未确认的其他高级写法：除已开放的特肖模式、岁写法、各->各肖外，未冻结规则的写法不强行识别。
- 未确认规则的复杂玩法：胆拖、组选、全包、复选、连码和平尾正式结算等；完整规则未确认前不接入正式结算。
- 云同步 / 在线账号：当前定位为本地桌面记账工具，不接入在线账号体系。
- 正式安装包：当前可做测试版打包检查，正式安装包发布流程未冻结。
