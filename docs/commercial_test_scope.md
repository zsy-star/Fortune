# 商用测试版 / 内部试用版范围

Fortune 当前版本状态统一为：商用测试版 / 内部试用版。它面向小范围商用记账验证，优先保证订单、结算、日志、备份恢复和导出对账流程稳定；功能边界以本文档和 `feature_status.md` 为准。

## 已完成 / 可正常使用

- 录单弹窗解析、预览、保存订单。
- 录单窗口申报人选择，并保存到订单数据。
- 录单窗口显示申报人绑定的赔率/返水配置方案名称。
- 订单查询、订单详情、订单作废、订单详情查看。
- 订单详情页申报人筛选、投注类型筛选、中奖情况筛选。
- 订单详情页过滤结算结果、综合结算摘要、结算快照摘要展示。
- 订单导入预览、确认导入成功行、txt/csv/xlsx、模板下载、申报人、渠道、历史重复检测。
- 开奖记录查询、开奖记录采集、手工新增开奖记录、修正选中开奖记录。
- 结算预览、正式确认结算、结算记录持久化。
- 结算历史 / 账目流水只读查询。
- 操作日志查询。
- 数据总览和订单分析真实数据库统计。
- 数据库备份 / 恢复。
- 订单、结算流水、操作日志 Excel 导出。
- 设置中心：赔率/返水配置方案、申报人配置、导入/导出秘钥本地持久化。
- 全局数据变更自动刷新：订单、日志、结算、开奖、设置、数据库恢复。
- 号码大全静态参考。
- 计算器。

## 第一阶段可用

- 录单高级选项：
  - 已开放：识别地区、智能纠错、特肖模式、岁写法、各->各肖。
  - 边界：特肖模式、岁写法、各->各肖只影响录单解析、预览和保存口径；不自动结算、不写余额、不涉及真实兑奖。
  - 未确认的其他高级写法：规则未冻结前不强行识别。
- 拆单助手：
  - 已开放：文本整理、订单预览、勾选保存解析成功行、复制结果、保存 UTF-8 txt、写操作日志。
  - 未接入：复杂玩法自动纠错、自动结算、赔付金额、余额。
- 特码调单：
  - 已开放：只读汇总、页面内临时调整、保存调单快照记录、查看记录、复制、导出、打印提示文本。
  - 未接入：真实修改原订单、真实兑奖、自动赔付、余额。
- 连肖调单：
  - 已开放：左侧总表 + 右侧四列表只读汇总、保存调单快照记录、查看记录、复制、导出、打印提示文本。
  - 未接入：真实修改原订单、真实打印机调用、连肖兑奖、余额。
- 结算：
  - 已开放：命中 / 未中 / 不支持判断、部分复杂玩法、基础中奖金额第一阶段、快照和历史展示。
  - 未接入：余额流水、客户账户、返水、佣金。

## 只读展示

- 结算历史和结算快照详情只读展示正式结算保存时的数据。
- 订单详情页底部澳门 / 香港 / 综合结果区只读展示结算摘要。
- 号码大全为静态参考表，不自动随年份更新。
- 调单页面保存的调整记录仅为快照，不修改订单状态。

## 未开放功能冻结清单

- 余额流水 / 客户账户：账务模型、审计口径和回滚策略尚未设计，不写客户余额。
- 返水 / 佣金：当前只计算基础中奖金额，返水和佣金不参与结算。
- 权限系统：角色、授权范围和管理员审计尚未设计，不开放高风险维护权限。
- 清空订单：破坏性操作，需要权限、审计和恢复策略支持。
- 清空日志：操作日志用于追溯订单、结算、备份恢复等关键行为，不提供清空入口。
- 批量删除：需要权限、审计和恢复策略支持，当前不开放。
- 重置开奖：会影响结算依据，需要权限、审计和恢复策略支持。
- 真实兑奖：涉及结算、赔付、余额流水和审计，当前不执行真实兑奖。
- 真实修改原订单式调单：需要审计、权限和回滚策略，当前调单只保存快照。
- 真实打印机调用：需要打印模板和设备适配，当前只生成可复制/导出的打印文本。
- 录单窗口未确认的其他高级写法：除已开放的特肖模式、岁写法、各->各肖外，未冻结规则的写法不强行识别。
- 未确认规则的复杂玩法：胆拖、组选、全包、复式组合等；完整规则未确认前不接入正式结算。
- 云同步 / 在线账号：当前定位为本地桌面记账工具，不接入在线账号体系。
- 正式安装包：当前可做测试版打包检查，正式安装包发布流程未冻结。

## 高风险功能暂不开放

- 清空订单、清空日志、批量删除等破坏性操作。
- 绕过结算预览直接改订单状态。
- 未确认规则前的复杂玩法自动结算。
- 未设计审计和回滚策略前的真实改订单式调单。
- 未设计权限系统前的管理员级维护入口。

## 测试原则

- 不显示假业务数据。
- 未开放入口必须隐藏、禁用或明确标记。
- 第一阶段功能必须明确说明写入边界；例如导入和拆单可保存成功行，调单只保存快照，不修改原订单。
- 所有订单、结算、开奖、日志、设置数据变更应触发自动刷新。
- 不写入真实测试数据到 `data/fortune.db`。
