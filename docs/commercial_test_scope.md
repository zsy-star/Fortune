# 商用测试版 / 内部试用版范围

Fortune 当前版本状态统一为：商用测试版 / 内部试用版。它面向小范围商用记账验证，重点是号码录入、订单统计、开奖核对、结算快照、操作日志、备份恢复和导出对账。

Fortune 不做客户账户、不做客户余额、不做余额流水、不做真实兑奖入账，不涉及真实资金支付。中奖金额和返水金额只是统计参考。

## 已开放

- 录单、预览、保存订单。
- 录单高级选项：识别地区、智能纠错、特肖模式、岁写法、各->各肖。
- 订单查询、详情、导出、作废。
- 订单导入：txt/csv/xlsx、模板、申报人、渠道、历史重复检测、确认导入成功行。
- 拆单助手：文本整理、订单预览、勾选保存成功行。
- 开奖同步、手动新增、修正。
- 结算预览、正式结算、结算历史。
- 多种玩法命中 / 未中 / unsupported 判断。
- 基础中奖金额快照。
- 赔率 / 返水配置方案，申报人绑定配置方案。
- 返水金额作为结算统计项和快照字段，不入账、不付款、不形成客户余额。
- 订单分析、操作日志。
- 特码调单 / 连肖调单快照保存。
- 调整记录查看、复制、导出、打印文本。
- 设置中心、备份恢复、号码大全、计算器。

## 边界

- 调单只是快照保存，不修改原订单、不自动兑奖、不写余额。
- 打印只是生成文本或导出，不是真实打印机调用。
- 中奖金额只是按录入金额和赔率计算出的快照 / 统计参考。
- 返水金额只是按投注额和返水比例计算出的快照 / 统计参考。
- 订单分析的盈亏 / 中奖金额不等于完整真实盈亏。
- 复选、连码、平尾等部分玩法只支持录单金额预览，正式结算仍 unsupported。

## 不纳入当前产品范围

- 客户账户。
- 客户余额。
- 余额流水。
- 手工加款 / 手工扣款。
- 真实兑奖入账。
- 真实支付 / 收款 / 付款。
- 冲正 / 回滚 UI。

## 仍未开放

- 权限系统 / 登录 / 角色 / 审批。
- 清空订单。
- 清空日志。
- 批量删除。
- 重置开奖。
- 真实修改原订单式调单。
- 真实打印机调用。
- 云同步 / 在线账号。
- 正式安装包。
- 规则未确认的胆拖、组选、全包等复杂玩法正式结算。

## 测试原则

- 不显示假业务数据。
- 不写真实测试数据到 `data/fortune.db`。
- 已开放功能必须能通过 UI 触达并写操作日志。
- 未开放高风险入口必须隐藏、禁用或明确标记。
- 资金相关功能不得以客户余额、流水、入账或支付形式出现。
