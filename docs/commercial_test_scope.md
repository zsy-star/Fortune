# 商用测试版范围

Fortune 当前测试版面向小范围商用记账验证，优先保证订单、结算、日志、备份恢复和导出对账流程稳定。

## 已完成 / 可正常使用

- 录单弹窗解析、预览、保存订单。
- 录单窗口申报人选择，并保存到订单数据。
- 录单窗口显示申报人绑定的赔率/返水配置方案名称。
- 订单查询、订单详情、订单作废、订单详情查看。
- 订单详情页申报人筛选、投注类型筛选、中奖情况筛选。
- 订单详情页过滤结算结果、综合结算摘要、结算快照摘要展示。
- 开奖记录查询、开奖记录采集、手工新增开奖记录、修正选中开奖记录。
- 结算预览、正式确认结算、结算记录持久化。
- 结算历史 / 账目流水只读查询。
- 操作日志查询。
- 数据总览和订单分析真实数据库统计。
- 数据库备份 / 恢复。
- 订单、结算流水、操作日志 Excel 导出。
- 设置中心：赔率/返水配置方案、申报人配置、导入/导出秘钥本地持久化。
- 全局数据变更自动刷新：订单、日志、结算、开奖、设置、数据库恢复。
- 号码大全静态参考。
- 计算器。

## 第一阶段可用

- 录单高级选项：
  - 已开放：识别地区、智能纠错。
  - 仍禁用：特肖模式、抄写法、各->各肖。
- 拆单助手：
  - 已开放：文本整理、去空行、压缩空格、按分隔符拆行、复制结果、保存 UTF-8 txt。
  - 未接入：订单解析、金额计算、保存订单、复杂玩法拆单。
- 特码调单：
  - 已开放：只读汇总、页面内临时调整、清空临时调整、清空输出框。
  - 未接入：真实调整保存、真实兑奖、赔付计算、调整记录持久化。
- 连肖调单：
  - 已开放：左侧总表 + 右侧四列表只读汇总、打印提示、清空输出框、重置页面临时状态。
  - 未接入：真实调整保存、真实打印机调用、连肖兑奖、赔付计算。

## 只读展示

- 结算历史和结算快照详情只读展示正式结算保存时的数据。
- 订单详情页底部澳门 / 香港 / 综合结果区只读展示结算摘要。
- 号码大全为静态参考表，不自动随年份更新。
- 调单页面当前只展示订单汇总，不修改订单状态。

## 暂未开放

- 订单导入。
- 批量删除订单。
- 清空订单。
- 清空操作日志。
- 真实调单调整保存。
- 真实打印机调用。
- 复杂玩法结算：连肖、多生肖、连尾、胆拖、组选、全包等。
- 赔付金额、中奖金额计算。
- 余额流水、客户账户。
- 权限系统、云同步、在线账号。
- PyInstaller 正式安装包。

## 高风险功能暂不开放

- 清空订单、清空日志、批量删除等破坏性操作。
- 绕过结算预览直接改订单状态。
- 未确认规则前的复杂玩法自动结算。
- 未设计审计策略前的真实调单保存。
- 未设计权限系统前的管理员级维护入口。

## 测试原则

- 不显示假业务数据。
- 未开放入口必须隐藏、禁用或明确标记。
- 第一阶段功能必须明确说明“不写数据库”或“不保存订单”。
- 所有订单、结算、开奖、日志、设置数据变更应触发自动刷新。
- 不写入真实测试数据到 `data/fortune.db`。
