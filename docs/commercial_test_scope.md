# 商用测试版范围

Fortune 当前测试版面向小范围商用记账验证，优先保证订单、结算、日志、备份恢复和导出对账流程稳定。

## 已开放

- 录单弹窗保存订单
- 订单查询、详情、作废
- 开奖记录查询
- 结算预览和正式确认结算
- 结算历史 / 账目流水只读查询
- 操作日志查询
- 数据总览和订单分析
- 数据库备份 / 恢复
- Excel 导出
- 号码大全静态参考
- 计算器

## 暂未开放

- 连码调单、连肖调单持久化
- 拆单助手
- 订单导入、批量删除、清空订单
- 清空操作日志
- 兑奖、赔率、赔付金额、盈亏金额
- 权限系统、云同步

## 测试原则

- 不显示假业务数据。
- 未开放入口必须隐藏、禁用或明确标记。
- 不修改数据库模型和迁移。
- 不写入真实测试数据到 `data/fortune.db`。
