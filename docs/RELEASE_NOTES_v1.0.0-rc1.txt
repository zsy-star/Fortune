FORTUNE 1.0.0-rc1 发布候选说明
================================

规则版本：FORTUNE_RULESET_2026_V2
数据库版本：20260715_0010

这是第一版正式发布候选包，供小范围验收使用。

当前正式结算支持：
- 特码号码、特码生肖及已支持的特码属性
- 平码、平特一肖、平特一肖带主肖
- 平尾、平特0尾、普通连肖、N不中
- 二中二、三中三、三中二

当前暂不支持正式结算：
- 连肖复选、几中几复选、二中特、二中特复选、特串
- 四肖、包半波、连尾、正码特、通用胆拖、无明确基础玩法的复3

数据安全提示：
- 升级前必须先备份数据库。
- 恢复数据库后建议重启软件。
- 程序目录中的 data、logs、exports 为用户运行数据，升级时不得直接覆盖。
- 发布包不包含开发机数据库、赔率方案、订单、结算记录或用户配置。

已知限制：
- 本版本不含云同步、自动更新和真实资金账户功能。
- 未列入正式支持清单的玩法继续受结算门禁保护。
- 当前没有独立安装程序；发布形式为Windows onedir ZIP。
