# FORTUNE V1.0 简易使用手册

## 一、软件用途

FORTUNE 是本地单机记账和统计工具，可以录单、查询订单、管理开奖、预览和确认结算、查看结算历史、记录调单、备份恢复及导出表格。

本软件不包含客户余额、真实收付款、真实兑奖入账和云同步。中奖金额、返水金额和统计结算金额仅用于记账与对账，不代表已经付款或入账。所有数据都保存在当前电脑中。

## 二、如何启动

1. 将收到的压缩包完整解压到一个固定文件夹。
2. 不要只复制或移动 `Fortune.exe`，它必须和旁边的文件夹一起使用。
3. 打开解压后的 `Fortune` 文件夹。
4. 双击 `Fortune.exe`。
5. 首次启动请稍等，软件会创建本地数据文件。
6. 不要在压缩包内直接运行软件。

## 三、首次使用设置

1. 点击主窗口右上角的 **“设置”**。
2. 打开 **“申报人”** 页，输入名称并点击 **“添加申报人”**。
3. 打开 **“赔率/返水”** 页，选择或新增配置方案，再添加常用玩法、赔率和返水。
4. 双击表格可修改数据；修改后点击 **“保存表格修改”**，并确认申报人绑定了正确方案。
5. 关闭设置窗口，打开 **“我要录单”**，确认申报人可以选择。

> **提醒：**不熟悉的赔率不要随意填写。正式结算前一定确认申报人绑定的赔率方案。N不中应按具体阶数配置，例如“十不中”。

## 四、如何录单

1. 点击顶部的 **“我要录单”**。
2. 选择渠道、申报人、**“澳门（快捷键1）”**或**“香港（快捷键2）”**，并确认计算方式和生肖年份。
3. 在左侧输入框粘贴或输入订单；软件会自动识别，也可点击 **“快速预览”**重新识别。
4. 需要表格核对时点击 **“添加结果”**，检查投注类型、订单信息、金额、每号金额和结算支持。
5. 有红色错误或金额不符时先修改原文，不要直接保存。
6. 确认无误后点击 **“保存订单”**。

> 录单窗口不手工选择期号和日期。订单会记录保存时间；正式结算时再在“结算预览”中选择开奖期号。

常用示例：

特码：

```text
01 100
```

多个号码：

```text
01 13 25各20
```

多个生肖独立下注：

```text
牛兔马猪各包10
```

显式连肖：

```text
四连肖猪牛马虎 70
```

十不中：

```text
6 18 31 43 22 10 03 15 01 13 十不中 4000
```

- “四连肖”整组只算一注，示例总金额为 70。
- “牛兔马猪各包10”表示牛、兔、马、猪分别下注 10，总金额为 40。
- “十不中 4000”表示整组金额为 4000，不是每个号码 4000。
- 保存前必须人工核对识别结果。
- 显示 **“暂不支持”**或“暂不支持正式结算”的玩法可以按提示保存记账，但不能正式结算。

## 五、如何查询订单

1. 点击 **“订单详情”**。
2. 可按地区、投注类型、中奖情况、申报人、渠道、状态或日期筛选，也可搜索订单号。
3. 选中订单，在 **“所选订单详情”**中查看原文和明细。
4. 需要导出时点击 **“导出订单”**。
5. **“作废订单”“清空订单”“批量删除选中订单”**都要谨慎操作。

## 六、如何录入开奖

1. 点击 **“今日开奖”**查看最新开奖；点击 **“开奖记录”**管理历史开奖。
2. 在开奖记录中可点击 **“获取最新数据”**或 **“同步历史数据”**。
3. 手工录入时点击 **“手工新增开奖”**。
4. 核对地区、期号、日期、6个正码和1个特码后再保存。
5. 修正时先选中记录，点击 **“修正选中开奖”**并填写真实原因；已用于正式结算的开奖不要随意修改。

## 七、如何结算

1. 在 **“订单详情”**中选中待结算订单，点击 **“结算预览”**。
2. 在弹窗中选择正确开奖期号，再点击 **“开始预览”**。
3. 核对开奖号码、赔率、判定结果、中奖金额、返水金额和统计结算金额。
4. 确认全部正确后，点击 **“正式确认结算”**。
5. 到 **“结算历史”**选中记录，点击 **“查看结算快照详情”**复核。

> **正式结算前必须先看预览。**不支持玩法会被系统阻断；已正式结算的订单不能重复结算。结算快照用于事后查账，不代表真实付款或入账。

## 八、如何使用调单

### 特码调单

1. 打开 **“特码调单”**，选择 **“只看澳门”**或**“只看香港”**，并确认生肖年份。
2. 查看每个号码的原金额、已抛、调整和调整后金额。
3. 在 **“调整额”**输入框输入 `25=100`，按 Enter 应用。
4. 核对调整结果，点击 **“保存本次调整”**。
5. 点击 **“调整记录”**查询历史；需要撤销时选中记录并点击 **“撤销抛出”**。

### 连肖调单

1. 从 **“特码调单”**旁的菜单打开 **“连肖调单”**，选择地区和生肖年份。
2. 查看生肖组合、持有金额和盈亏。
3. 在 **“调整输入”**中输入 `猪牛马虎=100`，按 Enter 应用。
4. 核对后点击 **“保存本次调整”**。
5. 需要查询或撤销时打开 **“调整记录”**。

> 调单只保存抛出记录，不修改原订单，不重新结算，也不会写入客户余额。

## 九、如何备份和恢复

### 备份

1. 打开 **“辅助工具”**。
2. 找到 **“数据库备份 / 恢复”**。
3. 点击 **“立即备份”**。
4. 确认页面提示“备份成功”。

### 恢复

1. 在备份列表中选中需要恢复的文件，仔细核对创建时间。
2. 点击 **“从备份恢复”**。
3. 阅读覆盖提示，确认无误后继续。
4. 恢复成功后关闭并重新打开软件。

> 建议每天结束后备份一次；大批量录单、开奖修正和正式结算前也应备份。恢复会覆盖当前数据，必须谨慎。不要随意删除 `data/backups` 中的文件。

## 十、如何查看日志和号码大全

### 操作日志

- 点击 **“操作日志”**，可按模块、操作、操作人、关键词和日期查询记录。
- 录单、开奖、结算、调单和备份等关键操作会保留日志。
- 出现问题时点击 **“导出表格”**保存查询结果。

### 号码大全

- 点击 **“号码大全”**，可查看2026生肖号码、波色、半波、五行及其它参考分类。
- 可切换生肖年份，并使用 **“搜索”“上一个”“下一个”**定位内容。
- 民间分类和附件五行等内容只是静态参考，不表示录单和结算全部支持。

## 十一、高风险操作提醒

> **以下操作必须谨慎：清空订单、批量删除选中订单、清空日志、重置开奖/重置开奖记录、从备份恢复。**

执行前请：

1. 先点击 **“立即备份”**并确认成功。
2. 核对要操作的地区、日期、订单或记录范围。
3. 界面要求时填写真实原因。
4. 界面要求时输入正确的确认短语，并认真阅读最后一次确认。
5. 操作完成后检查 **“操作日志”**和剩余数据。

## 十二、常见问题

### 1. 软件打不开怎么办？

- 确认压缩包已经完整解压。
- 不要单独移动 `Fortune.exe`。
- 检查杀毒软件是否拦截了程序或旁边的运行文件。

### 2. 订单识别失败怎么办？

- 检查输入格式，减少不必要的特殊符号。
- 一条订单一行，复杂内容可拆开输入。
- 使用“去分割符”“去空格”或“号码补零”前，先保留原始内容。
- 仍有问题时保留输入原文、提示文字和截图。

### 3. 为什么可以保存但不能结算？

- 部分玩法只支持记账，暂不支持正式结算。
- 以录单窗口的“结算支持”和结算预览提示为准。

### 4. 为什么调单页面没有最新订单？

- 先确认订单已经保存成功且地区选择正确。
- 重新进入“特码调单”或“连肖调单”，页面会重新加载订单汇总。
- 特码调单可点击“重置所有数据”，连肖调单可点击“重置调整”，清除当前未保存调整后重新查看。

### 5. 恢复数据库后数据显示不对怎么办？

- 关闭并重新打开软件。
- 检查所选备份的创建时间。
- 不要继续录入，先保留当前日志和最近备份。

### 6. 出现问题需要保留什么？

- 订单号、地区和期号。
- 输入原文和软件截图。
- 操作日志导出文件。
- 最近备份文件的名称和时间。

## 十三、每日推荐操作顺序

打开软件
→ 检查设置、地区和开奖期号
→ 录单并核对
→ 备份
→ 录入或同步开奖
→ 结算预览
→ 正式确认结算
→ 导出对账
→ 再次备份

## 十四、最后提醒

- 本软件只在当前电脑保存数据，换电脑不会自动同步。
- 重要操作前先备份。
- 录单识别结果必须人工核对。
- 正式结算前必须查看预览并核对开奖和赔率。
- 暂不支持正式结算的玩法请人工核对。
- 不要把真实数据库或备份文件随意发送给别人。
