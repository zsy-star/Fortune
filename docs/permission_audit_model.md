# 权限与审计模型

本文冻结 Fortune 后续开放高风险能力前的权限与审计设计口径。当前只作为设计约束，不代表功能已经实现。

## 当前状态

- 当前版本状态为：商用测试版 / 内部试用版。
- 当前暂未实现登录、账号、角色、权限审批。
- 当前高风险入口仍保持禁用或只给出明确提示。
- 当前不开放清空订单、清空日志、重置开奖、真实兑奖、真实修改原订单式调单、余额修改。
- 当前只允许使用已有受控功能：作废订单、修正开奖记录、正式确认结算、保存调单快照。

## 未来角色设计建议

| 角色 | 建议职责 |
| --- | --- |
| 管理员 | 管理用户、角色、权限方案和高风险操作审批。 |
| 录单员 | 新增订单、导入订单、拆单助手保存成功行、查看基础数据。 |
| 财务员 | 查看结算、确认受控结算、处理未来余额流水和冲正。 |
| 审计员 | 查看订单、结算、操作日志、调单记录和审计报表，不直接改业务数据。 |
| 只读查看员 | 只读查看订单、开奖、结算历史和统计报表。 |

## 权限分级

### 普通权限

- 查看订单。
- 新增订单。
- 导入订单。
- 拆单助手保存。
- 查看开奖。
- 查看结算历史。
- 查看操作日志。

### 中风险权限

- 作废订单。
- 修正开奖记录。
- 正式确认结算。
- 保存调单快照。

### 高风险权限

- 清空订单。
- 清空日志。
- 批量删除。
- 重置开奖。
- 真实兑奖。
- 真实修改原订单式调单。
- 修改余额流水。
- 修改客户账户余额。
- 修改赔率方案并影响结算。

## 审计日志要求

每个中风险和高风险操作都必须记录审计日志，并且审计日志不可被业务流程绕过。至少记录：

- 操作时间。
- 操作人。
- 操作模块。
- 操作类型。
- 影响对象 ID。
- 操作前摘要。
- 操作后摘要。
- 原因。
- 二次确认标记。
- 客户端环境信息，如后续可取。

## 高风险操作开放条件

清空、重置、真实兑奖、真实调单、余额修改等高风险操作必须同时满足：

- 权限系统完成。
- 审计日志不可绕过。
- 二次确认。
- 可恢复或备份机制。
- 测试覆盖。
- 文档更新。

## 当前冻结结论

- 当前不开放清空订单。
- 当前不开放清空日志。
- 当前不开放重置开奖。
- 当前不开放真实兑奖。
- 当前不开放真实修改原订单式调单。
- 当前不开放余额修改。
- 当前只允许作废订单、修正开奖、正式结算、保存调单快照这些已有受控功能。
